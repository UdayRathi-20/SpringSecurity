# Spring Security Authentication System

## Project Overview
A Spring Boot application demonstrating authentication and authorization using Spring Security. The project secures endpoints, manages user access, and provides role-based security features.

## Features
- User Authentication
- Endpoint Security
- Role-Based Authorization
- Secure Password Handling
- Spring Security Integration
- REST API Protection

## Tech Stack
- Java
- Spring Boot
- Spring Security
- Maven

## Project Structure
```
src/
 ├── main/
 │   ├── java/
 │   └── resources/
 └── test/
```

## How to Run

### Clone Repository
```bash
git clone https://github.com/UdayRathi-20/SpringSecurity.git
```

### Navigate to Project
```bash
cd SpringSecurity
```

### Run Application
```bash
mvn spring-boot:run
```

### Access Application
```text
http://localhost:8080
```
